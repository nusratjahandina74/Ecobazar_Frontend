# EcoBazaar Frontend (white & green)
React 19 + Vite + Tailwind 4 + react-router, wired to the EcoBazaar Express backend.

    cp .env.example .env     # set VITE_API_BASE_URL if the API is not on http://localhost:5000
    npm install
    npm run dev              # http://localhost:5173
    npm run build && npm run lint

See ../INTEGRATION_REPORT.md for routes, roles and backend changes.
